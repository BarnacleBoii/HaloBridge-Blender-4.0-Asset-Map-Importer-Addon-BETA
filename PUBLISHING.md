# Release procedure

Run the tests and scripts/package.py. Upload only the audited source tree. Attach the installable addon ZIP and matching source ZIP to the versioned GitHub beta pre-release. Preserve repository visibility and prior releases. Never include game files, local fixtures, caches or diagnostics. Owner-supplied docs/halobridgelogo.png is the sole allowed image asset.

For the v0.9 refresh, include every user guide, including docs/IMPORTING.md, in both attached archives. Check internal links and old version references. Use the same source commit for the refreshed installer and attached source ZIP; if retaining an older release tag, explain that GitHub's automatic tag archives differ from the refreshed attached source. Preserve owner edits made on GitHub before syncing a local documentation tree.
